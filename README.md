# Hospital Emergency & Appointment System

A Java console project built from scratch, without built-in collections.

## Features
- Emergency patients treated by severity (priority queue)
- Appointments served first come, first served (queue)
- Undo last action (stack)
- All patient records (linked list)

## How to run
Open the folder in IntelliJ IDEA and run Main.java

## Time complexity
- Priority queue enqueue: O(n), dequeue: O(1)
- Queue and stack operations: O(1)
